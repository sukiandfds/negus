## 文件

- prompt.txt：实际发送的指令。
- metadata.json：对话及完成信息。
- source-visible-output.json：从本测试对话原始记录提取的可见输出与工具调用，保留原始顺序。
- events.json：浏览器收到的实时事件；页面存在多个事件连接，同一事件可能重复记录，核对时按标识去重。
- requests.json：本次页面 POST 请求结果。
- ui-transitions.jsonl：运行中列表、顶部、工作过程和可见消息的变化，每秒采样，可能略过极短状态。
- history-before-refresh.json、history-after-refresh.json：刷新前后的消息历史。
- ui-before-refresh.txt、ui-after-refresh.txt、ui-after-reopen.txt：对应页面文字。
- before-refresh.png、after-reopen.png：对应截图。

## 聊天列表新增需求与后续边界

用户标注位置为 ConversationRows 的 contact-preview。正在执行的对话应在这里展示实时状态，包括未选中的对话；后续其他功能可以提供状态描述。

现有基础：useProjectDirectory 已按 threadId 接收所有对话的状态；部分列表行丢失了 label；展示优先级中 preview 优先于 active 状态，会存在状态被静态文字遮盖的可能。

实现时应复用同一套状态文案供聊天顶部和列表使用，避免两处各自判断；预留状态描述的来源和优先级，但不提前开发未提出的功能或复杂状态框架。
