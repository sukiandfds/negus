# Negus / Your work. Your way.

30-second brand film, 1920 × 1080, 30fps. Original motion design and synthesized score; no external music, footage or private product data.

Install dependencies with `pnpm install`. Preview using `pnpm studio`; render using `pnpm exec remotion render src/index.tsx NegusBrand negus-brand-30s.mp4 --browser-executable='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'`.

The six scenes cover ideas, personal assistant, workspace, project collaboration, personal organization, and the closing brand. UI is a stylized illustration of the product positioning, not a recording or acceptance demonstration of pending automation features. Logo geometry comes from the current Negus app icon.
