## 获准上线后逐条执行

1. 确认切换能力的发布版本已生效，且对应项目已授权给 00。通过 `conversation_model_get` 记录真实当前值、待应用值、最后成功值和原线程编号；从 `conversation_list` 核对对话归属及原绑定。保留一个既有历史消息用于回核。
2. 00 对原线程调用 `conversation_model_set`，传本表的 `modelProviderId`、`model`、`effort`。在设置 → 对外助手 → 活动中，确认原对话链接、旧新配置和服务端认证的真实发起人正确，状态为待生效。若对话正在运行，沿用既有保护，等原任务结束；不改变排队规则。
3. 经获准执行的下一轮继续在原对话发送，核对实际路由、思考等级、回复和既有历史。重读当前值及最后成功值，刷新活动页，核对同一调用从待生效变为已生效，原会话编号、身份和历史保持。
4. 接续失败时，核对活动的失败状态、原绑定仍有效、失败关联原提交；停在该条排查。若确需回切且原渠道可用，按同一入口选择步骤 1 的原值，在下一轮核对路由和历史。余额停用的旧渠道不可作为未经确认的回切目标。
