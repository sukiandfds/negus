## 运行与安全边界

- Python 标准库 SQLite helper 与 @iarna/toml 结构化解析配置，不启动 CC Switch、不改全局 Codex live 文件。
- 写入前使用 SQLite 在线备份保存到 CC Switch backups/negus-*.db，事务写入并检查并发配置变化，保留未知字段和当前选择。
- 当前启用的 CC Switch 渠道禁止从 Negus 编辑，提示先在桌面切到其他渠道，避免数据库与 Codex live 配置不一致。
- Key 沿用 CC Switch 数据库原有存储方式，不宣称该数据库加密；Negus 运行副本用现有 DPAPI 加密。Key 不回显到浏览器，不进入日志、聊天或浏览器持久化。
- 已运行的 Negus 渠道保留旧运行配置直到安全重启，不中断任务。未运行渠道重新读取共享配置。桌面列表即时刷新尚未验证，必要时刷新或重新打开 CC Switch。
- 仅启用有 HTTPS API 地址、可读取 API Key、默认模型且使用 responses 协议的渠道。官方 OAuth、自定义认证命令和其他应用渠道暂不支持编辑/启用。不探测模型、不声称实际调用可用。
- 倍率优先读取已有浮生账户令牌分组表与 pricing，并用实际 Key 查询 token 名称；仅同供应商域名、完整令牌列表且同名匹配仅有一个分组时展示供应商分组倍率。同名多分组、查询失败或其他供应商不猜价格，显示“配置倍率”。不按渠道名称猜分组。顶部对共享渠道显示所选渠道供应商倍率，不继续借用固定 GPT 分组倍率；未核实时显示 --。无自动比价、账单、删除、故障转移或全局渠道切换。
- 接口沿用工作区既有授权，尚无独立渠道管理员权限，不扩大为多人密钥系统。
