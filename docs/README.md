## 仍待设计，不能自动变成待办

- 总助理、系统主管、运营助手、项目经理的职责关系；长期与临时 Agent 的创建条件。
- 专业 Agent 何时直接答、何时后台执行、何时需要多人意见；快速意图判断是否值得额外调用。
- Codex 兼容的最低承诺、已有工作的连续性和安全交接；没有决定放弃兼容，也没有承诺无缝双向同步。
- 默认桌面内容、主动推荐、任务展示、通知频率和自主改进范围。
- 用户行为信息、私聊共享、模板跨用户复用的权限和数据边界。
- 目标客户、收费方式与首个付费场景。

这些开放问题来自 9 月 24/28 日记录。旧文档中的优先级和“下一步”是历史计划，只有重新确认适合当前方向后才进入当前计划。
