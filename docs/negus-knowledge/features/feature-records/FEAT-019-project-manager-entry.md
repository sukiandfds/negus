# FEAT-019 项目面板单项目经理 AI 入口

## 用户体验

- 用户在项目管理页的项目概览中点击“与项目经理讨论”，进入长期的 `manager` Agent 单聊。
- 入口会将当前项目的 ID、名称、阶段和目标带入对话地址，单聊标题区显示“项目经理上下文”，避免用户误以为进入了无关的普通对话。
- 仍使用现有真实 Codex 员工会话、流式执行、历史和恢复链路，不新建一套项目经理聊天协议。

## 实现边界

- 项目管理页负责入口和上下文导航；`openAgentConversation` 负责打开或复用长期员工会话。
- URL 上下文用于当前对话的可见定位，不会自动替用户发送一条消息，也不会改变员工会话的文件归属或权限。
- 项目上下文尚未注入 Codex 的开发者指令；用户需要在单聊中确认后再发送具体任务。

## 验证

- `pnpm build:ui` 通过（TypeScript 检查和 Vite 生产构建）。
- 未启动常驻服务，尚未完成浏览器点击、真实员工 Runtime 和移动端验收。

## 回滚

移除项目概览按钮、导航参数和标题区上下文显示即可，不影响现有员工单聊或项目管理数据读取。
