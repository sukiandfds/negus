# FEAT-020：内测访问入口与共享链接

## 用户可见目标

独立内测入口已于 2026-09-16 23:15 +08:00 按用户授权移除，统一使用原有分享入口。共享授权和 Cookie 机制保留。以下 v0.1.0 实现和验收条目仅为历史记录。

## v0.1.0 历史实现

- 标题栏提供“内测入口”按钮，调用现有 `GET /api/share-link` 生成入口链接。
- 对话框显示这是共享内测链接而非独立账号，提醒只发给信任的内测成员。
- 链接生成失败时显示错误和“重试”，生成成功后支持复制。
- 首次带令牌访问时，前端把令牌留在本次页面加载的内存中，同时从可见地址栏移除；服务端写入 `codex_demo_token` HttpOnly、SameSite Cookie。
- API 请求仅在本次加载确实取得查询令牌时附加令牌；后续请求优先依赖 Cookie，避免无意义地把令牌复制到每个请求 URL。

## 明确边界

- 当前仍是单个工作区的共享访问令牌，不是账号注册、登录、成员邀请或细粒度权限系统。
- 链接持有者可获得该工作区当前令牌允许的访问范围；不要把它当作公开注册入口。
- 账号、组织成员、登录提供商、令牌轮换和撤销需要独立的身份服务设计，不在本次最小交付中伪造。
- 没有启动服务或进行公网、手机和多浏览器实机验收；真实内测前仍需验证 Cookie、固定域名、Tunnel 和 origin 均在线。

## 验收条件

1. 已授权页面可以打开“内测入口”，生成并复制链接。
2. API 失败时页面不会卡死，用户可以重试或关闭对话框。
3. 首次链接访问后，浏览器地址栏不再保留令牌；同源 API 仍可通过 Cookie 访问。
4. 无效或缺失授权仍返回 401，不能因为前端隐藏令牌而放开 API。
5. 应用代码不主动把令牌写入日志或无关请求 URL。
