<p class="text-base mb-4 leading-relaxed!"><strong>Recover</strong> and <strong>Reset</strong> both rebuild from your last saved data. If the computer can&#x27;t be reached to save first, very recent changes may be lost. If Bots recently disappeared, or saving failed, <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a> before you use either one.</p>
<h2 class="text-medium mt-12 mb-4" id="which-should-i-try-first"><a class="group flex items-center no-underline hover:no-underline" href="#which-should-i-try-first" data-heading-base-id="which-should-i-try-first" aria-label="Copy link to which-should-i-try-first"><span data-heading-highlight-target="true">Which should I try first?</span><span class="ml-2 text-muted-foreground opacity-0 transition-opacity group-hover:opacity-100"><div class="relative size-3" aria-hidden="true"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-copy absolute inset-0 size-3 transition-all duration-200 ease-in-out opacity-100 scale-100" aria-hidden="true"><rect width="14" height="14" x="8" y="8" rx="2" ry="2"></rect><path d="M4 16c-1.1 0-2-.9-2-2V4c0-1.1.9-2 2-2h10c1.1 0 2 .9 2 2"></path></svg><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-check absolute inset-0 size-3 text-green-600 transition-all duration-200 ease-in-out opacity-0 scale-50" aria-hidden="true"><path d="M20 6 9 17l-5-5"></path></svg></div></span></a></h2>
<ol class="mb-4 prose-ol-markers" style="list-style-type:decimal;list-style-position:outside;padding-left:calc(4rem / 3);line-height:1.5">
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Wait, then choose <strong>Retry</strong> if the computer says <strong>Reconnecting</strong> or <strong>Couldn&#x27;t Reach Grok Bot&#x27;s Computer</strong>. Bots, files, and logins are safe while it reconnects. Do not <strong>Reset</strong> during this.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Fully quit Grok Bot and reopen it. On Mac, choose <strong>Quit</strong> from the menu bar, not just close the window.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Update</strong> the computer from <strong>Settings &gt; Updates</strong> if an update is offered.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Recover</strong> if it still cannot reconnect, or if an update looks stuck and <strong>Recover computer</strong> is shown. On a slow update, <strong>Keep waiting</strong> is the safe default.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Reset</strong> only after those steps. Like <strong>Recover</strong>, it can lose very recent changes if the computer can&#x27;t be reached to save them.</li>
</ol>
<p class="text-base mb-4 leading-relaxed!">Do not start a second Update or Reset while one is already running. Repeated resets can interrupt a restore that is still finishing.</p>

<ul class="my-6 prose-ul-markers" style="list-style-type:square;list-style-position:outside;padding-left:calc(4rem / 3);line-height:1.5">
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Reconnecting</strong> and <strong>Recover</strong> usually take a few minutes. You can choose <strong>Continue in Background</strong>.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">An <strong>Update</strong> can also take a few minutes when it is downloading a large image or transferring data. If it says <strong>Update still running</strong>, keep waiting.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Choose <strong>Recover</strong> only if the update appears stuck and the app offers <strong>Recover computer</strong>. If recovery is not available, keep waiting.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">If <strong>Recover</strong> or <strong>Reset</strong> fails, use <strong>Retry Recovery</strong> or <strong>Retry Reset</strong> once. Then stop and <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a>.</li>
</ul>

<p class="text-base mb-4 leading-relaxed!">The computer&#x27;s data is not safely backed up yet. Grok Bot will offer the update again after a backup completes. Wait for that. Do not <strong>Reset</strong> to force the update.</p>
<p class="text-base mb-4 leading-relaxed!"><strong>Agent busy</strong> means a bot could not pause in time, so the computer was not updated. Let that bot finish, then update again.</p>

<p class="text-base mb-4 leading-relaxed!">Check the computer first. A bot cannot finish a turn while the computer says <strong>Reconnecting</strong> or <strong>Couldn&#x27;t Reach Grok Bot&#x27;s Computer</strong>. Follow <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="#which-should-i-try-first">Which should I try first?</a>, then send the message again.</p>
<p class="text-base mb-4 leading-relaxed!">If the computer is connected and the same prompt still fails, <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a>. <p class="text-base mb-4 leading-relaxed!">Grok Bot keeps a durable copy of synced computer data. Reopening the computer restores from that copy, so synced files usually come back. If the computer is still empty after <strong>Recover</strong>, stop making changes inside it and <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a>.</p>
<p class="text-base mb-4 leading-relaxed!">Files that exist only on your Mac or Windows machine are not covered. Keep your own backups for those.</p>

<h2 class="text-medium mt-12 mb-4" id="my-chats-or-bots-look-missing-were-they-deleted"><a class="group flex items-center no-underline hover:no-underline" href="#my-chats-or-bots-look-missing-were-they-deleted" data-heading-base-id="my-chats-or-bots-look-missing-were-they-deleted" aria-label="Copy link to my-chats-or-bots-look-missing-were-they-deleted"><span data-heading-highlight-target="true">My chats or bots look missing. <p class="text-base mb-4 leading-relaxed!">Often no. Chats are stored separately from the computer, so a computer problem does not delete conversation history by itself. Check before you <strong>Reset</strong>.</p>
<ol class="mb-4 prose-ol-markers" style="list-style-type:decimal;list-style-position:outside;padding-left:calc(4rem / 3);line-height:1.5">
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Fully quit Grok Bot and reopen it. On Mac, choose <strong>Quit</strong> from the menu bar, not just close the window.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Open the same account on another device, including the iPhone app. Bots and conversations are shared across devices signed into that account.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">In the sidebar, open <strong>Hidden Bots</strong> on desktop or <strong>Show Hidden Bots</strong> on the phone. <strong>Hide from sidebar</strong> removes a Bot from the list only. <p class="text-base mb-4 leading-relaxed!">A disk warning is not data loss. <strong>Computer is low on disk space</strong> or <strong>Computer is critically low on disk space</strong> means Disk Saver is auditing usage and will propose safe cleanup. Nothing is deleted without confirmation. <strong>Disk Saver</strong> is a Bot in the sidebar. Choose <strong>Go to Disk Saver</strong> to review what it proposes. Declining leaves those files in place. Cleanup applies only to computer files you confirm, not to chats.</p>
<p class="text-base mb-4 leading-relaxed!"><strong>Recover</strong> and <strong>Reset</strong> are different. Both can lose very recent changes if the computer can&#x27;t be reached to save them. Don&#x27;t use either one to look for chats that seem missing. <p class="text-base mb-4 leading-relaxed!"><strong>Recover</strong> and <strong>Reset</strong> both rebuild from your last saved data. If the computer can&#x27;t be reached to save first, very recent changes may be lost. If Bots recently disappeared, or saving failed, <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a> before you use either one.</p>
<h2 class="text-medium mt-12 mb-4" id="which-should-i-try-first"><a class="group flex items-center no-underline hover:no-underline" href="#which-should-i-try-first" data-heading-base-id="which-should-i-try-first" aria-label="Copy link to which-should-i-try-first"><span data-heading-highlight-target="true">Which should I try first?</span><span class="ml-2 text-muted-foreground opacity-0 transition-opacity group-hover:opacity-100"><div class="relative size-3" aria-hidden="true"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-copy absolute inset-0 size-3 transition-all duration-200 ease-in-out opacity-100 scale-100" aria-hidden="true"><rect width="14" height="14" x="8" y="8" rx="2" ry="2"></rect><path d="M4 16c-1.1 0-2-.9-2-2V4c0-1.1.9-2 2-2h10c1.1 0 2 .9 2 2"></path></svg><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="lucide lucide-check absolute inset-0 size-3 text-green-600 transition-all duration-200 ease-in-out opacity-0 scale-50" aria-hidden="true"><path d="M20 6 9 17l-5-5"></path></svg></div></span></a></h2>
<ol class="mb-4 prose-ol-markers" style="list-style-type:decimal;list-style-position:outside;padding-left:calc(4rem / 3);line-height:1.5">
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Wait, then choose <strong>Retry</strong> if the computer says <strong>Reconnecting</strong> or <strong>Couldn&#x27;t Reach Grok Bot&#x27;s Computer</strong>. Bots, files, and logins are safe while it reconnects. Do not <strong>Reset</strong> during this.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Fully quit Grok Bot and reopen it. On Mac, choose <strong>Quit</strong> from the menu bar, not just close the window.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Update</strong> the computer from <strong>Settings &gt; Updates</strong> if an update is offered.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Recover</strong> if it still cannot reconnect, or if an update looks stuck and <strong>Recover computer</strong> is shown. On a slow update, <strong>Keep waiting</strong> is the safe default.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Reset</strong> only after those steps. Like <strong>Recover</strong>, it can lose very recent changes if the computer can&#x27;t be reached to save them.</li>
</ol>
<p class="text-base mb-4 leading-relaxed!">Do not start a second Update or Reset while one is already running. Repeated resets can interrupt a restore that is still finishing.</p>

<ul class="my-6 prose-ul-markers" style="list-style-type:square;list-style-position:outside;padding-left:calc(4rem / 3);line-height:1.5">
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px"><strong>Reconnecting</strong> and <strong>Recover</strong> usually take a few minutes. You can choose <strong>Continue in Background</strong>.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">An <strong>Update</strong> can also take a few minutes when it is downloading a large image or transferring data. If it says <strong>Update still running</strong>, keep waiting.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Choose <strong>Recover</strong> only if the update appears stuck and the app offers <strong>Recover computer</strong>. If recovery is not available, keep waiting.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">If <strong>Recover</strong> or <strong>Reset</strong> fails, use <strong>Retry Recovery</strong> or <strong>Retry Reset</strong> once. Then stop and <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a>.</li>
</ul>

<p class="text-base mb-4 leading-relaxed!">The computer&#x27;s data is not safely backed up yet. Grok Bot will offer the update again after a backup completes. Wait for that. Do not <strong>Reset</strong> to force the update.</p>
<p class="text-base mb-4 leading-relaxed!"><strong>Agent busy</strong> means a bot could not pause in time, so the computer was not updated. Let that bot finish, then update again.</p>

<p class="text-base mb-4 leading-relaxed!">Check the computer first. A bot cannot finish a turn while the computer says <strong>Reconnecting</strong> or <strong>Couldn&#x27;t Reach Grok Bot&#x27;s Computer</strong>. Follow <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="#which-should-i-try-first">Which should I try first?</a>, then send the message again.</p>
<p class="text-base mb-4 leading-relaxed!">If the computer is connected and the same prompt still fails, <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a>. <p class="text-base mb-4 leading-relaxed!">Grok Bot keeps a durable copy of synced computer data. Reopening the computer restores from that copy, so synced files usually come back. If the computer is still empty after <strong>Recover</strong>, stop making changes inside it and <a class="text-foreground underline decoration-neutral-600 underline-offset-2 transition-colors hover:decoration-neutral-700" href="/help/grok-bot/get-help">contact support</a>.</p>
<p class="text-base mb-4 leading-relaxed!">Files that exist only on your Mac or Windows machine are not covered. Keep your own backups for those.</p>

<h2 class="text-medium mt-12 mb-4" id="my-chats-or-bots-look-missing-were-they-deleted"><a class="group flex items-center no-underline hover:no-underline" href="#my-chats-or-bots-look-missing-were-they-deleted" data-heading-base-id="my-chats-or-bots-look-missing-were-they-deleted" aria-label="Copy link to my-chats-or-bots-look-missing-were-they-deleted"><span data-heading-highlight-target="true">My chats or bots look missing. <p class="text-base mb-4 leading-relaxed!">Often no. Chats are stored separately from the computer, so a computer problem does not delete conversation history by itself. Check before you <strong>Reset</strong>.</p>
<ol class="mb-4 prose-ol-markers" style="list-style-type:decimal;list-style-position:outside;padding-left:calc(4rem / 3);line-height:1.5">
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Fully quit Grok Bot and reopen it. On Mac, choose <strong>Quit</strong> from the menu bar, not just close the window.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">Open the same account on another device, including the iPhone app. Bots and conversations are shared across devices signed into that account.</li>
<li style="padding-inline-start:4px;margin:0 0 0.5rem 0;font-size:15px">In the sidebar, open <strong>Hidden Bots</strong> on desktop or <strong>Show Hidden Bots</strong> on the phone. <strong>Hide from sidebar</strong> removes a Bot from the list only. <p class="text-base mb-4 leading-relaxed!">A disk warning is not data loss. <strong>Computer is low on disk space</strong> or <strong>Computer is critically low on disk space</strong> means Disk Saver is auditing usage and will propose safe cleanup. Nothing is deleted without confirmation. <strong>Disk Saver</strong> is a Bot in the sidebar. Choose <strong>Go to Disk Saver</strong> to review what it proposes. Declining leaves those files in place. Cleanup applies only to computer files you confirm, not to chats.</p>
<p class="text-base mb-4 leading-relaxed!"><strong>Recover</strong> and <strong>Reset</strong> are different. Both can lose very recent changes if the computer can&#x27;t be reached to save them. Don&#x27;t use either one to look for chats that seem missing.
