# Negus 提示词与对话详情：评审用现状说明

2026-11-23 ｜ 对象：普通对话、员工对话、群聊中的员工。依据为当前 develop 工作区代码。本文区分已经运行的机制和待讨论的设计。

**现在已经打通的一条路径：普通对话的当前助手写话题记录，详情面板读它，下一轮助手也读它。** 面板里其余内容各有来源：工具执行来自运行记录，后台任务来自任务账本，日程来自调度器。打开面板不会启动一个助手重新总结，也不会把整页面板发给模型。

## 1. 一次回答是怎样组装的

1. **共用指令。** 顺序是「Negus 系统提示词 → 工具目录 → 入口提供的角色和附加要求」。系统提示词由服务端 AGENTS.md 和内置的交付、授权、表达规则等拼成。工具目录列名称、用途、说明文件位置；具体说明在选用时再读。普通对话复用 negus助手的岗位文件，仍保留普通线程和话题机制。
2. **本轮输入。** 用户消息和附件进入当前线程。应用另行准备本轮模型标识，以及这个入口适用的资料，见下表。已有对话历史由线程承接。
3. **发送前去重。** 对带开发者指令的 turn/start，共用发送层按线程比较用户画像、员工补充资料、话题召回和模型标识。相同内容跳过，首次或变化时追加；普通对话本轮专属的草稿路径和写入说明仍会发送。去重状态在服务进程内，重启或记录淘汰后会重新比较并发送。

| 入口 | 助手额外得到什么 | 跟对话详情是什么关系 |
|---|---|---|
| 普通对话（非托管线程） | 本轮话题草稿路径、写入规则；已有主线、最近最多 6 个话题的 ID、标题和累计摘要，以及完整索引路径 | 当前已接通“写话题 → 面板展示 → 后续回答召回”的入口 |
| 员工主对话 | 岗位要求；不自动附加成长记录 | 成长记录保存在员工档案。托管线程跳过普通对话的话题草稿，不自动生成同款话题记录 |
| 群聊中的员工 | 本次交办、协作要求；群聊走任务入口 | 群任务与当前普通对话的话题文件分开 |

**成本。** 员工单聊、群聊和后台任务不再自动附加成长记录。旧实现会对相同内容去重，因此不能按记录长度乘以轮数推算节省。已进入线程历史的文字保留。

## 2. 详情面板中的内容从哪里来

| 面板内容 | 谁生产、何时更新 | 后续回答如何利用 |
|---|---|---|
| 话题标题、摘要 | 当前普通对话助手在最终回复前按需写草稿。本轮成功结束才发布。同话题按 ID 更新累计摘要，新话题新增，一轮可写多项，无新进展就跳过 | 与面板共用已发布记录。最近 6 项按上节规则召回；完整历史有索引路径 |
| 对话主线 | 助手和摘要一起写入 mainline；召回取最近更新记录的主线 | 已从面板删除展示，仍作为助手后续回答的参考 |
| 正在运行、历史步骤、工具与产物 | 运行状态和实际执行记录；展开话题后，按关联轮次 turnIds 取步骤和产物 | 可追溯助手做过什么。面板的读取接口不把命令明细追加到下一轮提示词 |
| 后台任务、日程 | 分别按来源对话查任务账本、按线程查调度器。两者独立更新 | 派工结果可按任务机制回传；日程由调度器触发。两者都不靠话题摘要驱动 |

**为什么摘要读起来像交接笔记？** 写入要求明确说“更新累计摘要”，后端检查标题、主线、摘要是否有内容；没有单独要求一句面向用户的结果。列表直接取同一段摘要显示前两行，展开又显示全文。例如“已推送到 develop”这个话题里，提交号、文件数和用户关心的“远端是否核对一致”共用一个摘要字段。要改善首屏质量，可以先评审写作目标，无需先决定换模型。

## 3. 供评审者判断的三个问题（设计候选，均未实施）

- **什么该留在这一次对话？** 例如用户在本轮说“先别发布”，应保留为当前事项的约束。现有话题 ID 和关联轮次能保存来龙去脉。若同时需要“一句最新结果”和“长期累计摘要”，评估让同一执行助手一次写两种用途的内容，保留无新进展时跳过的规则。
- **什么值得带到其他对话？** 当前已有 USER_PROFILE.md 的读取入口：按安装位置读取，最多取 12,000 个字符，变化时注入。这与“从对话详情自动写用户画像”是两条链路；现有话题发布流程只写本线程记录。评审时宜区分用户明确表达的稳定偏好、单次反馈和助手推测的情绪。例如“以后先给结论”可以作为偏好候选；“这次回答让我很烦”应保留当时的对象和原因，不能直接改写成长期性格标签。
- **谁负责写画像？** 当前助手最了解这句话针对什么，且可在本轮提出有原话依据的候选；额外助手适合跨多次对话去重、处理矛盾，但会多一次读取和推理。可用同一组对话比较：能否区分长期偏好与临时要求、能否准确引用来源、用户纠正后能否撤销，以及实际增加的延迟与 token。这个选择不影响继续使用现有话题文件和画像读取入口。
