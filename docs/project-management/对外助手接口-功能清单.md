# Negus 对外助手接口 · 功能清单（已确认，含开发前修正）

2026-11-24，按 develop 工作区（基线 09f85a5）盘点。以下是建议契约，不是已上线工具。00 指 Muse。业务范围按用户能完成的动作划分；同一动作的手机、网页、员工会话入口合并，扩展路由、独立应用挂载和本机能力另列。项目有登记但尚未接通的能力见末节。

**怎么读：** 每个签名给出输入和返回的业务字段。标识均为服务端发放的不透明 ID；问号表示可选。除项目目录及明确系统级查询外，每次调用都必须绑定已授权的 project；写请求还带唯一 requestId。分页返回游标；拒绝、失败、重复提交均返回同一个可追查的调用编号。只读档只查询；派活档增加业务记录或驱动内部工作；修复档可改配置、代码和运行状态。标为须审批的工具只返回待办编号，永不直接提交。H 项：凭证查看属只读、修改及批准属写入，删除凭证或撤销令牌等属不可逆；无一开放。U 项区分本地偏好写入和纯展示读取，不设远程风险档。

## 不可从原入口直接继承的权限

- 现有网页授权检查保护 /api 和事件流；分享链接会返回访问令牌。00 使用单独可撤销的带令牌接入链接，仅本人界面展示；不把网页会话、原始链接、请求头或密钥写进消息、历史、诊断或工具结果。服务端按令牌确定 external:00；不接受调用方填 createdBy、reviewedBy 或成员号。
- 对外发送、删数据、合并主分支、部署等，按最终效果判定。自由文本派工、改图上传供应商、跨项目转发、带项目内容的模型请求、云调用和后台员工都不能成为绕行入口。涉及对外发送的请求在内容离开前转待审批；只读资料查询不能携带项目私有内容。审批绑定接收方、参数、内容版本；变更后重新申请，重复回调不重复执行。只有本人界面的决定可驱动后续执行。
- 本人的桌面能点击批准、读凭证；外部任务不能继承这类无限制执行环境。需要代码修复的员工也只能在受约束的项目执行环境工作；不能从 shell、宿主文件、共享账号、网络或自行派子任务跨过审批。若下游无法执行相同约束，该调用应显示具体阻塞，不能把启动当作成功。
- 员工长期会话归员工，工作成果归工作项目（FEAT-017）。在现有任务、会话、发布、产出及审核记录中关联 workProjectId、source、调用和父任务；项目视图沿引用汇集，不复制正文和文件。话题读已发布记录，画像走候选通道；不动缓存注入、不重构对话存储。全局设置与全局画像要过滤到可披露的字段。
