# Negus 单人功能与 Codex Desktop 横向对标调研

- 调研日期：2026-09-16；任务编号：RESEARCH-005（本报告标识，未另建项目管理条目）。
- 工程基线：`codex/publish-current-panel`，`0353352ba24e6e18a040437e5ba4bb28a1cef805`，并包含调研时已有未提交改动。
- 桌面基线：本机 Windows 包 `OpenAI.Codex 26.908.9136.0`。不能把包版本等同于 CLI 版本。
- 本阶段交付：功能、使用体验、后台机制及页面样式的分类差异报告；不实施功能对齐，不恢复此前回退的共享运行时方案。
- 范围：单个用户从打开项目、输入任务、执行、介入、检查成果到长期使用的完整路径。群聊和组织协作不纳入开发范围，只用于说明共享模块边界。

## 1. 核心判断

Negus 已有真实 Codex 会话主链路。发送、停止、队列、模型和强度、压缩、Goal、分叉、归档、历史分页、流式回复、事件恢复等不应重新列为从零开发。

最显著的缺口是用户介入闭环、草稿可靠性、完整开发工作区、真实能力管理，以及后台功能是否与桌面使用相同配置。页面相似不能证明能力相同：顶部菜单是装饰；`/skill` 和 `/app` 是自然语言转换；命令时间线不等于交互终端；原生 review 调用不等于 Diff 工作台；项目历史入口不等于长期记忆。

优先顺序：先消除交互死胡同和数据丢失，再补工作区及工具管理，再核验后台继承和持续运行，最后统一样式。Desktop/Web 同会话锁按既有要求作为独立专项，不夹带在页面对齐中开发。
